前情提要

2026/3/15 起，新簽發的公開信任 TLS 憑證最長效期已從 398 天縮短為 200 天；2027/3/15 降至 100 天，2029/3/15 降至 47 天。

管理 100 張憑證，從 398 天縮為 47 天後，估計年續期量由約 92 次增至 777 次。本課用 Bob 協助自動換證，減少漏換、部署錯誤與服務中斷。

來源：CA/Browser Forum §6.3.2。次數按到期續期估算；私有 PKI 不受上述效期上限限制。

Workshop 目標

課內實作：

  • 用 Bob 理解 TLS 憑證生命週期：申請 → 部署 → 監控 → 輪換。
  • 使用 Vault PKI，或自行建立 OpenSSL 測試 CA 並簽發憑證。
  • 用 Bob 產生 Agent 設定、Shell 或 Ansible，自動部署至 Liberty。
  • 驗證線上憑證、重複執行結果，並確認重複執行結果。

延伸練習： 用 Bob 建立完整 PKI、AGENTS.md、/check-cert Slash Command、可重用 Skill，以及 Frontend Slides 成果簡報。 Cheat sheet 參考：Bob Cheat Sheet

如何連線

IP、帳號與 SSH key 已匯入 Bob 的 SSH config。在 Bob IDE Terminal 輸入表格中的 SSH 指令即可登入。

ssh liberty1   # 第 1 組；其他組改用自己的編號

需要登入共用 Vault 時，在學員電腦的另一個 Terminal 執行 ssh vault。輸入 exit 離開遠端主機。Vault API 位址與憑證路徑依各 Part 步驟確認。

組內角色分工

每組 5 人，建議分配為 1＋3＋1，也可採 2＋2＋1。

角色人數任務與交付
🔐 Vault 與憑證管理1～2 人申請憑證、檢查 SAN／效期／信任鏈，交付憑證與設定檔位置
🤖 自動化／Liberty／維運2～3 人完成部署、線上驗證與重跑檢查，交付執行結果
📑 統整報告員1 人記錄架構、前後憑證序號與修復方式，整理交接；簡報為延伸

由一位操作員負責部署，避免同時修改 keystore；共用 Vault 設定由講師管理。Token、私鑰與密碼不要貼進 Bob 對話。
